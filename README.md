# 🖥️ ElevenLabs Y2K Redesign

> *What if ElevenLabs was built in 2001?*

A full Y2K / early-2000s redesign of the ElevenLabs homepage — same product, completely different era. Built for **ElevenHacks Hackathon #6** using v0 by Vercel and the ElevenLabs API.

🔗 **Live site:** [v0-elevenlabs-y2k-redesign-17u6.vercel.app](https://v0-elevenlabs-y2k-redesign-17u6.vercel.app)

---

## ✨ Features

- **Y2K Visual Style** — Windows XP beveled buttons, animated marquee, glowing cyan typography, scanline overlay, retro grid background
- **🎙️ Voice Tour** — Floating button that narrates each section of the site using ElevenLabs TTS API with a deep synthetic voice
- **▶️ Play Demo** — Interactive audio demo powered by ElevenLabs, embedded directly in the page
- **Full Next.js App** — Production-ready, deployed on Vercel

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- An [ElevenLabs API key](https://elevenlabs.io/app/settings/api-keys)

### Installation

```bash
git clone https://github.com/pablomg-dev/v0-elevenlabs-y2k-redesign
cd v0-elevenlabs-y2k-redesign
pnpm install
```

### Environment Variables

Create a `.env.local` file in the root:

```env
NEXT_PUBLIC_ELEVEN_API_KEY=your_api_key_here
```

### Run locally

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to see the result.

## 🎨 Design Style

The redesign reimagines ElevenLabs with authentic Y2K aesthetics:

- **Colors:** Electric cyan `#00FFFF`, hot pink `#FF00FF`, black, silver chrome
- **Typography:** Impact / Comic Sans for headlines, Courier New for body
- **UI Elements:** Beveled 3D buttons, animated marquee, blinking cursors, scanlines
- **Vibe:** Internet Explorer 6 era meets cutting-edge voice AI
